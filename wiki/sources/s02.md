# S02 vLLM v0.11.0 Metrics 設計

[第一手原文](https://docs.vllm.ai/en/v0.11.0/design/metrics.html)
範圍：v0.11.0，V1 Design。核對：2026-11-11。

同一服務可以量到排隊、輸入與輸出區間。必須先指定計時邊界，才可比較數字。

## 整理的主張

- [C03](../topics/stages.md#c03)：請求到達後可能先等待排程；排隊時間與模型實際處理輸入的時間可以分開觀察。（定位：V1 Design → Interval Calculations）
- [C04](../topics/metrics.md#c04)：首個 token 的等待時間（TTFT），在這裡指服務前端接收請求到收到第一個輸出 token 的時間。（定位：V1 Design → Frontend Stats Collection）
- [C05](../topics/metrics.md#c05)：相鄰輸出 token 的間隔（ITL）看的是後續 token 到達的節奏。（定位：V1 Design → Interval Calculations）
- [C06](../topics/metrics.md#c06)：這裡的完成時間從服務前端收到請求算到最後一個 token。（定位：V1 Design → Frontend Stats Collection）
