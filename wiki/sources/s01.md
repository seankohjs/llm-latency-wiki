# S01 DistServe 原始論文

[第一手原文](https://arxiv.org/html/2401.09670v3)
範圍：arXiv v3，2024，§2.1。核對：2026-11-11。

研究把推論分成處理 prompt 與接續生成兩種工作。取用階段定義，不轉用研究環境中的效能數字。

## 整理的主張

- [C01](../topics/stages.md#c01)：Prefill 處理輸入的 prompt，建立後續生成所需的狀態，並形成第一個輸出 token。（定位：§2.1 LLM Inference）
- [C02](../topics/stages.md#c02)：Decode 接續生成後面的 token；後續輸出會依賴先前的上下文與已生成的 token。（定位：§2.1 LLM Inference）
