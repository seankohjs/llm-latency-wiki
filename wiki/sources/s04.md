# S04 vLLM v0.11.0 Automatic Prefix Caching

[第一手原文](https://docs.vllm.ai/en/v0.11.0/features/automatic_prefix_caching.html)
範圍：v0.11.0，Introduction／Limits。核對：2026-11-11。

相同前綴的可用 KV 狀態可以跨請求重用。需要區分輸入計算節省與新 token 的生成。

## 整理的主張

- [C09](../topics/prefix.md#c09)：自動前綴快取（APC）讓新請求重用相同前綴的可用 KV 狀態，減少該段 prefill 的重複計算。（定位：Introduction／Example workloads）
- [C10](../topics/prefix.md#c10)：APC 減少共同前綴的輸入處理工作，並不直接縮短後續每個新 token 的 decode 計算。（定位：Limits）
- [C11](../topics/prefix.md#c11)：沒有可重用前綴時，不能靠該段快取省下計算；若等待主要來自長輸出，整體改善也可能有限。（定位：Limits）
