# S03 PagedAttention 原始論文

[第一手原文](https://arxiv.org/html/2309.06180)
範圍：2023，§2.2、§4.1–4.3。核對：2026-11-11。

KV cache 保存先前 token 的注意力狀態。原論文用區塊管理這些資料，避免為每個請求預留整段連續空間。

## 整理的主張

- [C07](../topics/kv.md#c07)：KV cache 保存先前 token 已算出的注意力 key、value，讓後續生成可以使用這些狀態。（定位：§2.2 與 §4.3）
- [C08](../topics/kv.md#c08)：PagedAttention 把 KV cache 以區塊管理，可隨序列長度配置，區塊不必在記憶體中連續。（定位：§4.1–4.2）
